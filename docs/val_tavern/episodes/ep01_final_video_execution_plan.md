# 《炼狱酒馆 EP01：单摸芮娜，赢了战绩输了全队》终版视频执行方案

## 1. 版本目标

本方案用于 EP01 正式视频生成阶段，统一栏目名称、角色关系、台词、时长结构和 6 个 Clip 的最终提示词。后续如继续生成视频，应严格以本方案为准。

本版重点：

- Clip 01 采用“开场动画 + 栏目包装 + 本集导入”的形式。
- 总时长控制在 48–52 秒，目标约 50 秒。
- 强化角色动画表现力，避免站桩说话。
- 保持 Q版二次元、霓虹酒馆、玩家排位吐槽的统一风格。

## 2. 全局设定

- 栏目名称：炼狱酒馆
- 画幅：竖屏 9:16
- 风格：Q版二次元、霓虹酒馆、暖橙色 + 紫色灯光
- 氛围：赛后排位复盘吐槽、轻喜剧、玩家社区梗
- 发布方向：抖音短视频

## 3. 角色定位

| 角色 | 定位 | 表演重点 |
| --- | --- | --- |
| 老瓦 | 酒馆老板，稳，开场和收尾控场 | 举杯、抬手叫停、淡定看戏 |
| 皮蛋 | 黄色圆滚滚吉祥物，护目镜，举牌担当 | 小跳、晃身体、举牌、可爱反应 |
| 贤者 | 暴躁受害者吐槽位 | 拍桌、前倾、指人、摊手、红温 |
| 芮娜 | 嘴硬、自信、战绩派 | 指自己、耸肩、摊手、抬下巴、翻白眼 |
| 捷风 | 阴阳怪气精准拆台位 | 抱臂、歪头、抬眉、嫌弃侧眼、冷笑 |
| 幽影 | 冷幽默补刀位 | 低头喝饮料、停顿、抬眼、低气压补刀 |

## 4. 必须保留与删除

必须保留：

- 老瓦开场：“要来一杯吗？”
- 皮蛋举牌：“今日特调：单摸战神”
- 结尾老瓦：“皮蛋，你怎么看？”
- 结尾皮蛋举牌：“都别吵了，KSKBL”

必须删除：

- 不使用老瓦中段解释台词。
- 不使用“刚输完？那先复盘”。
- 不使用“输了先别急着甩锅”。
- 不使用“酒还没醒，锅先上桌了”。

导火索处理方式：

- 开场后直接用“失败结算 + 芮娜 20-10-0 + 众人红温”的画面代替解释台词。

## 6. 角色动画强化规则

- 表情必须明确：红温、生气、无语、阴阳怪气、嘴硬、不服、自信都要看得出来。
- 眼神、眉毛、嘴型变化要明显。
- 一个角色说话时，其他角色也要有反应动作。
- 镜头运动服务笑点：开场有包装感，冲突段轻推近，幽影补刀留停顿，群吵段轻微横移，结尾推近皮蛋举牌。
- 禁止脸崩、乱抖、镜头乱转、动作失控、战斗化、血腥、写实真人。

## 8. Clip 最终提示词

### Clip 01｜开场动画 + 栏目包装 + 本集导入

竖屏 9:16，Q版二次元风格，霓虹酒馆“炼狱酒馆”场景，暖橙色和紫色灯光，短视频栏目感，画面稳定，角色表情清晰，动作生动。生成一个 11 秒短视频镜头。Clip 01 不是普通说话镜头，而是“开场动画 + 栏目包装 + 本集导入”的综合片段。

0–2s：炼狱酒馆招牌亮起，霓虹灯闪烁，开场动画感，建立栏目包装感。

2–4s：酒馆内景建立，吧台、圆桌、全息屏出现，老瓦在吧台后，皮蛋出现在画面里，建立空间和节目氛围。

4–6s：老瓦站在吧台后方举起一杯琥珀色发光饮料，表情淡定又老练，右臂机械义肢，不戴红色贝雷帽。老瓦有自然举杯动作、轻微点头和嘴型动作。下方清晰字幕：“老瓦：要来一杯吗？”

6–8s：镜头推到皮蛋。皮蛋保留特色形象：黄色圆滚滚、护目镜、可爱吉祥物。皮蛋先小跳一下，再高高举起一块牌子，身体轻微左右晃动，动作活泼。牌子中心清晰写着：“今日特调：单摸战神”

8–11s：镜头切到圆桌上的赛后结算屏，清楚显示“对局失败”和“芮娜 20-10-0”。同时画面里贤者扶额后拍桌，明显红温；捷风冷脸侧眼看芮娜；幽影低头喝饮料，气压很低；芮娜看着自己的战绩，表情自信又不服，甚至轻微抬下巴。全桌气氛凝固，像马上要吵起来。这一段不用额外台词字幕，只用画面表达“输了 + 芮娜 20-10-0 + 众人红温”。

### Clip 02｜贤者暴躁拍桌

竖屏 9:16，Q版二次元风格，炼狱酒馆室内，发光战术桌，短视频吐槽氛围，动作表情更夸张。

生成一个 6 秒短视频镜头。贤者站在发光战术桌前，情绪明显红温，动作要大：先拍桌，再指向芮娜，身体前倾输出。表情是破防又生气，不是冷静讲道理。其他角色在背景中有反应动作，比如芮娜不服、捷风冷脸、幽影安静旁观。

字幕直接生成在画面下方安全区，白字黑描边，分段显示：“整天就知道保你那破 KDA！”“进包点永远看不到你人！”贤者嘴型尽量匹配字幕内容，动作节奏要跟着台词爆点走。

### Clip 03｜芮娜嘴硬 + 捷风拆台

竖屏 9:16，Q版二次元风格，炼狱酒馆圆桌场景，霓虹灯氛围，短视频争吵感，角色动画更有戏。

生成一个 11 秒短视频镜头。芮娜和捷风在圆桌边对峙。

前半段突出芮娜：紫黑长发，紫色系服装，自信、嘴硬、理直气壮，有指自己、摊手、耸肩、抬下巴、翻白眼等动作。不是心虚，而是“我数据最好你们凭什么说我”。

后半段突出捷风：白发短马尾，蓝白色服装，冷淡、嫌弃、阴阳怪气，有抱臂、歪头、抬眉、冷笑、侧眼看芮娜等动作。说话时像精准拆台，不是纯发火。

字幕直接生成在画面下方安全区，白字黑描边，分段出现：“芮娜：我 20-10-0，全队评分最高。你们自己打不过，还好意思甩锅给我？”“捷风：0 首杀，0 助攻。进攻永远单摸在绕后，本质瘤子。只打安全枪，谁不会啊？”重点突出“20-10-0”“0 首杀”“0 助攻”“只打安全枪”。

### Clip 04｜芮娜继续嘴硬 + 幽影补刀

竖屏 9:16，Q版二次元风格，炼狱酒馆霓虹酒吧氛围，短视频剧情吐槽感，角色动画层次清楚。

生成一个 8 秒短视频镜头。芮娜继续为自己辩解，幽影坐在一旁冷静补刀。

前半段：芮娜站在前景，动作更生动，带一点夸张自信。一只手指自己，另一只手做“拉扯”的手势，抬下巴，语气很拽，表情像“你们根本不懂我”。字幕：“我那是在拉扯。懂不懂世界第一边路的压制力？”

后半段：幽影坐在阴影感更强的位置，黑紫斗篷，蓝色发光眼睛。动作要少，但要有戏：先低头喝一口饮料，停顿半秒，缓慢抬眼，冷冷开口补刀。字幕：“不怪你。你只是和队伍不在一个地图。”幽影要有冷幽默感，节奏慢一点。

### Clip 05｜众人争吵升级

竖屏 9:16，Q版二次元风格，炼狱酒馆圆桌争吵场景，群像构图清楚，动作反应要更丰富。

生成一个 9 秒短视频镜头。圆桌边多人争吵升级：芮娜站着反驳，贤者继续拍桌或摊手输出，捷风在旁边阴阳怪气补刀，幽影低气压冷冷收尾。

每个角色说话时都要有明显肢体动作。其他角色也要有反应，不能站桩。镜头可以轻微横向移动，制造“同桌吵起来”的热闹感。表情夸张但不要崩。

字幕直接生成在画面下方安全区，白字黑描边，逐句出现：“芮娜：那我不单摸，你们正面就一定打得进去吗？”“贤者：至少你人在，我们还能补枪！”“捷风：世界第一边路？我看是世界第一路边吧。”“幽影：她不是单摸。她是单机。”重点突出“世界第一路边”“她不是单摸，她是单机。”

### Clip 06｜老瓦点名 + 皮蛋收尾

竖屏 9:16，Q版二次元风格，炼狱酒馆收尾镜头，霓虹酒吧氛围，短视频结尾 punchline 感，动作可爱清晰。

生成一个 5 秒短视频镜头。众人争吵后，老瓦抬手示意大家停一下，动作稳但有控制感，表情淡定，像看惯这种场面的酒馆老板。随后镜头推到皮蛋。

皮蛋保留自己的特色形象，先小幅度跳一下，然后高高举起一块大牌子，动作活泼可爱，身体轻微晃动，牌子中心清晰写着：“都别吵了，KSKBL”

字幕直接生成在画面下方安全区，白字黑描边，分两段出现：“老瓦：皮蛋，你怎么看？”“皮蛋：都别吵了，KSKBL”结尾不要额外加评论引导，不要再加别的文案。

## 9. 统一负面提示词

不要写实真人，不要画风突变，不要新增角色，不要角色脸崩，不要严重镜头抖动，不要大幅旋转，不要战斗场景，不要血腥，不要水印，不要乱码字幕，不要错误中文，不要把字幕挡住角色脸，不要让牌子文字模糊，不要让老瓦戴红色贝雷帽，不要角色僵硬站桩。

## 10. 执行注意事项

- Clip 01 要明显有栏目片头感，不是直接开口。
- 开头必须交代清楚：这把输了、芮娜 20-10-0、队友已经红温。
- 贤者是最先爆的人，动作最大。
- 芮娜一定要嘴硬、自信、理直气壮，不是心虚。
- 捷风一定要阴阳怪气，不是单纯骂人。
- 幽影要短、冷、准，留停顿。
- 皮蛋举牌要准确、清晰、有记忆点。
- 优先保证台词能听清、字幕能读清、动作能看懂、梗点能成立。
