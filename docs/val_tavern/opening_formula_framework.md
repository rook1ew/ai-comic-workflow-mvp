# 《瓦酒馆》固定开场白框架 1.0

## 1. 开场设计目标

- 固定开场用于建立栏目记忆。
- 开场必须短，建议 2–3 秒内完成。
- 开场由“瓦叔主开场 + 皮蛋副标题 + 剧情冲突入口”组成。
- 当前阶段只搭框架，不最终锁死口号。
- 后续可以根据测试数据调整主开场句。

## 2. 标准开场结构

【0.0–0.5 秒】
瓦酒馆招牌亮起 / 吧台灯亮 / 皮蛋端酒跑过

【0.5–1.5 秒】
瓦叔说主开场句

【1.5–2.3 秒】
皮蛋举牌或托盘弹字幕：
今日上桌：XXXX

【2.3 秒后】
立刻进入本集剧情冲突

## 3. 四个固定模块

### 3.1 视觉钩子

可选画面：

- 瓦酒馆招牌亮起
- 皮蛋端酒跑过
- 今日特调牌闪一下
- 吧台灯光从暗到亮
- 账单啪地放到桌上

建议第一阶段优先使用：
皮蛋端酒跑过 + 酒馆招牌亮起

### 3.2 瓦叔主开场

当前默认句：
客官，要来一杯吗？

备选句：

- 客官，今晚喝哪杯？
- 来都来了，先坐。
- 这杯，算我请你看戏。
- 酒上桌，故事开场。
- 客官，今天这桌有意思。

说明：

- 主开场由瓦叔说。
- 声音要慵懒、低沉、有酒馆老板感。
- 不使用酒桶古拉加斯原音频。
- 必须使用原创配音。
- 不要做成广告腔。

### 3.3 皮蛋副标题

固定格式：
今日上桌：XXXX

表现方式：

- 皮蛋举牌
- 皮蛋端酒，托盘上弹出字幕
- 皮蛋递小纸条
- 皮蛋从画面边缘探头举牌

副标题示例：

- 今日上桌：奶妈不是你妈
- 今日上桌：火男又说他能进
- 今日上桌：奇乐小鸡失踪案
- 今日上桌：幽影今天不想说话
- 今日上桌：夜市开张
- 今日上桌：版本更新吐槽会
- 今日上桌：黑铁也有梦想
- 今日上桌：买完皮肤就马枪

### 3.4 剧情冲突入口

说明：

- 开场结束后必须立刻进入剧情。
- 不要在开场后再解释设定。
- 第一句台词最好直接抛出矛盾或笑点。

示例：

火男：奶妈，你刚才怎么不救我？
奶妈：我想救，但你死得太坚定了。

## 4. EP01 开场框架示例

标题：
《瓦酒馆 EP01：奶妈不是你妈》

【画面】
瓦酒馆招牌亮起，皮蛋端着发光饮料跑过。

【瓦叔】
客官，要来一杯吗？

【皮蛋举牌】
今日上桌：奶妈不是你妈。

【火男】
奶妈，你刚才怎么不救我？

【奶妈】
我想救，但你死得太坚定了。

## 5. 使用规则

- 开场总时长建议控制在 2–3 秒。
- 皮蛋副标题必须对应本集核心梗。
- 主开场可以测试多个版本，但同一阶段不要频繁变化。
- 不使用官方角色原音频作为固定片头。
- 不使用酒桶古拉加斯原音频。
- 后期字幕统一添加，不依赖生图里的文字。
- 皮蛋举牌图应尽量留白，方便后期加字。

## 6. 待测试问题

- “客官，要来一杯吗？”是否足够有记忆点。
- 是否需要更短版本：“要来一杯吗？”
- 皮蛋副标题用“今日上桌”还是“今日特调”。
- 开场是否保留瓦叔声音，还是只用字幕。
- 是否需要固定音效，如酒杯碰撞声、门铃声、皮蛋跑步声。
