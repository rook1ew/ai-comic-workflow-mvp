# 《瓦酒馆》固定开场白 1.0

## 1. 固定主口号

主口号：

要来一杯吗？

说明：

- 这是《瓦酒馆》当前固定开场白 1.0。
- 由瓦叔说出。
- 语气：慵懒、低沉、像酒馆老板招呼客人。
- 时长要短，不能拖慢剧情。
- 不使用酒桶古拉加斯原音频。
- 不使用任何官方角色原音频。
- 使用原创瓦叔配音。

## 2. 皮蛋副标题

固定格式：

今日上桌：XXXX

当前 EP01 测试副标题：

今日上桌：奶妈不是你妈

表现方式：

- 皮蛋举牌
- 皮蛋端酒，托盘上弹出字幕
- 皮蛋从画面边缘探头举牌

## 3. 标准开场结构

【0.0–0.5 秒】
瓦酒馆招牌亮起 / 皮蛋端酒跑过 / 吧台灯亮

【0.5–1.2 秒】
瓦叔：
要来一杯吗？

【1.2–2.2 秒】
皮蛋举牌：
今日上桌：奶妈不是你妈。

【2.2 秒后】
立刻进入剧情冲突

## 4. EP01 开场示例

标题：
《瓦酒馆 EP01：奶妈不是你妈》

【画面】
瓦酒馆招牌亮起，皮蛋端着发光饮料跑过。

【瓦叔】
要来一杯吗？

【皮蛋举牌】
今日上桌：奶妈不是你妈。

【火男】
奶妈，你刚才怎么不救我？

【奶妈】
我想救，但你死得太坚定了。

## 5. 使用规则

- 每集开场控制在 2–3 秒。
- 主口号固定为“要来一杯吗？”。
- 皮蛋副标题根据每集主题替换。
- 字幕和副标题后期添加，不依赖生图中文字。
- 不使用官方角色原音频。
- 不使用酒桶古拉加斯原音频。
- 如果后续测试发现“要来一杯吗？”不够有瓦叔人设，再考虑加回“客官”。
