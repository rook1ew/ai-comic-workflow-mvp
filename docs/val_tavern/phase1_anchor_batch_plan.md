# 《瓦酒馆》第一阶段锚点资产批次计划

## 1. 批次目标

第一批不继续扩展全量资产，而是先完成 5 个锚点资产，用最小闭环锁定栏目视觉标准：

- 锁定 Q版统一风格，明确 2.5 到 3 头身角色比例。
- 锁定赛博酒馆暖色霓虹氛围，避免后续资产风格漂移。
- 锁定角色识别语言，先确定瓦叔、皮蛋、捷风三类核心角色气质。
- 锁定酒馆道具视觉语言，先确定“今日特调牌”的可读性与可复用性。
- 为后续角色、道具、分镜和短视频镜头生成提供参考资产。

## 3. 分资产详细说明

### 3.1 瓦叔

- **资产定位**：原创酒馆老板，栏目主持气质与“今日特调”收尾仪式的核心锚点。
- **推荐使用的 prompt task**：`VG-PROMPT-001`、`VG-PROMPT-002`、`VG-PROMPT-003`
- **推荐输出数量**：3
- **推荐比例**：3:4
- **关键视觉要求**：中年大叔、胡茬、复古马甲、战术围裙、机械义手、发光酒杯、慵懒毒舌但亲切。
- **验收标准**：Q版比例稳定；机械义手和发光酒杯清楚；角色轮廓适合做参考图；没有官方误导表达。
- **后续复用方向**：瓦叔半身对话、今日特调收尾、封面主视觉、角色表情包。

### 3.2 皮蛋

- **资产定位**：酒馆吉祥物和小跑堂，承担递酒、递账单、举牌吐槽的喜剧动作。
- **推荐使用的 prompt task**：`VG-PROMPT-004`、`VG-PROMPT-005`、`VG-PROMPT-006`
- **推荐输出数量**：3
- **推荐比例**：3:4
- **关键视觉要求**：圆脸、憨憨可爱、小围裙、小托盘、可举牌、动作轻快。
- **验收标准**：表情可爱且可读；托盘和围裙清楚；角色比例与瓦叔统一；适合后续作为小图标和反应角色复用。
- **后续复用方向**：送酒跑堂、递账单、举梗牌、封面右下角小图标。

### 3.3 捷风

- **资产定位**：冷静毒舌和数据拆台位，负责建立“人间清醒”的角色参考。
- **推荐使用的 prompt task**：`VG-PROMPT-007`、`VG-PROMPT-008`、`VG-PROMPT-009`
- **推荐输出数量**：3
- **推荐比例**：3:4
- **关键视觉要求**：白发、数据平板、轻风特效、冷色边光、克制冷笑、靠窗数据感。
- **验收标准**：白发和数据平板辨识度高；毒舌但不凶狠；冷暖光不冲突；适合作为后续数据拆台镜头参考。
- **后续复用方向**：靠窗复盘、战绩拆台、半身封面、数据平板交互镜头。

### 3.4 瓦酒馆吧台全景

- **资产定位**：栏目主场景锚点，负责确定固定赛博酒馆空间和暖色霓虹基调。
- **推荐使用的 prompt task**：`VG-PROMPT-032`、`VG-PROMPT-033`
- **推荐输出数量**：2
- **推荐比例**：9:16，另保留 16:9 参考。
- **关键视觉要求**：吧台、原创瓦酒馆招牌、今日特调菜单、发光酒杯、禁止甩锅墙牌、原创赛事氛围装饰、角色站位留白。
- **验收标准**：竖屏构图可直接用于短视频；背景不抢角色；固定元素清楚；不复制官方素材。
- **后续复用方向**：开场建立镜头、群像互怼、片尾收束、角色站位参考。

### 3.5 今日特调牌

- **资产定位**：每集收尾金句载体，也是瓦叔仪式感和栏目识别的核心道具。
- **推荐使用的 prompt task**：`VG-PROMPT-022`
- **推荐输出数量**：2
- **推荐比例**：1:1
- **关键视觉要求**：赛博小黑板、暖色霓虹边框、大面积可替换文字区域、轮廓清晰、少量装饰。
- **验收标准**：文字区域可读且可替换；独立素材轮廓清楚；能放入吧台场景；不使用真实官方 LOGO。
- **后续复用方向**：今日特调金句卡、瓦叔手持动作、封面角标、吧台常驻装饰。

## 5. 验收标准

### 角色资产

- 是否符合 Q版统一风格，角色比例稳定在 2.5 到 3 头身。
- 是否符合赛博酒馆暖光氛围，并能与其他角色同场。
- 是否轮廓清晰，姿态明确，核心道具不遮挡脸部。
- 是否适合短视频竖屏栏目和后续半身镜头裁切。
- 是否适合作为后续角色生成的参考资产。
- 是否无官方误导表达，不使用真实官方 LOGO 或官方素材。

### 道具资产

- 是否轮廓清晰，可作为独立素材复用。
- 是否保留可替换文字区域，且文字区域足够干净。
- 是否符合赛博酒馆暖色霓虹视觉语言。
- 是否能自然放入吧台场景和模板中。
- 是否避免过多文字、过复杂细节和官方误导表达。

### 场景资产

- 是否符合固定赛博酒馆和暖色霓虹氛围。
- 是否预留角色站位或坐位，适合竖屏短视频构图。
- 是否包含栏目固定元素：原创酒馆标识、今日特调菜单、吧台、发光酒杯、禁止甩锅墙牌。
- 是否避免背景过度复杂，保证角色入镜后仍然清晰。
- 是否适合作为后续分镜和角色合成参考。
- 是否不复制官方素材、不使用真实官方 LOGO、不声称官方授权。
