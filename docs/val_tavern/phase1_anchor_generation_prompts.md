# 《瓦酒馆》第一阶段第一批锚点生图 Prompt 集

本文件整理第一批 5 个锚点资产的可直接复制 prompt。所有 prompt 仅用于粉丝二创资产生成准备，不生成真实图片，不使用真实官方 LOGO，不声称官方授权。
