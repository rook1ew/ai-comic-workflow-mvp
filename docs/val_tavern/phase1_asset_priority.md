# 《瓦酒馆》第一阶段资产制作优先级

## 第一优先级

这些资产决定栏目最小可运行形态，应优先完成。

| 资产 | 类型 | 原因 |
| --- | --- | --- |
| 瓦叔 | 角色 | 栏目原创主持与“今日特调”收尾核心 |
| 皮蛋 | 角色 | 跑堂、递道具、举牌笑点核心 |
| 捷风 | 角色 | 数据拆台和赛后复盘核心 |
| 酒馆吧台全景 | 场景 | 固定主场景，建立栏目识别度 |
| 今日特调牌 | 道具 | 每集收尾固定仪式 |
| 发光酒杯 | 道具 | 酒馆氛围和瓦叔动作核心 |
| 皮蛋小托盘 | 道具 | 皮蛋服务动作核心 |
| 皮蛋举牌板 | 道具 | 高频吐槽和梗文字载体 |
| 捷风数据平板 | 道具 | 数据拆台核心证据 |
| 禁止甩锅墙牌 | 道具 | 背景常驻梗，强化栏目语气 |

| 资产 | 类型 | 原因 |
| --- | --- | --- |
| 火男 | 角色 | 嘴硬和白给冲突核心 |
| 奶妈 | 角色 | 被甩锅与温柔补刀核心 |
| 奇乐 | 角色 | 可爱道具位和设备维修位 |
| 幽影 | 角色 | 冷幽默和角落金句位 |
| 吧台中景 | 场景 | 高频半身对话镜头 |
| 靠窗位 | 场景 | 捷风数据拆台专属空间 |
| 角落位 | 场景 | 幽影冷幽默专属空间 |

| 嘴硬指数牌 | 道具 | 火男嘴硬梗视觉化 |

## 第三优先级

这些资产用于扩展空间、客串和背景丰富度。

| 资产 | 类型 | 原因 |
| --- | --- | --- |
| 客串角色预留 | 角色 | 后续接入更多角色和事件梗 |
| 酒馆门口 | 场景 | 新角色入场位 |
| 后台工作区 | 场景 | 道具制作、调酒、维修场景 |
| 段位徽章展示牌 | 道具 | 强化瓦圈语境 |
| 赛事海报 | 道具 | 强化赛后酒馆背景 |
| 小电视 / 比分屏 | 道具 | 展示比分、回放和话题钩子 |
| 吧台酒瓶组 | 道具 | 提升场景完整度和氛围 |
