# 《炼狱酒馆》角色音色圣经

## 1. 老瓦 / Washu

- 声音方向：低沉、成熟、沧桑、酒馆老板感
- 语速：慢到中等
- 情绪：懒散、稳、像在看戏
- 禁止：不要像播音腔，不要太年轻
- 示例台词：要来一杯吗？

## 2. 皮蛋 / Pidan

- 声音方向：可爱、短促、萌音、可以轻微电子感
- 语速：偏快
- 情绪：开心、举牌、提示音感
- 禁止：不要过尖，不要吵
- 示例台词：今日特调，单摸战神！

## 3. 贤者 / Sage

- 声音方向：温柔但破防，委屈里带火气
- 语速：中等偏快
- 情绪：被坑后的压火吐槽
- 禁止：不要太凶，不要像骂人
- 示例台词：我们正面永远少一个，捷风 E 进去就没了，你人呢？

## 4. 芮娜 / Reyna

- 声音方向：自信、拽、嘴硬、强势
- 语速：中等偏快
- 情绪：理直气壮，不觉得自己有错
- 禁止：不要太尖叫，不要撒娇
- 示例台词：我 20-10，全队最高战绩，怪我？

## 5. 捷风 / Jett

- 声音方向：冷淡、阴阳怪气、不耐烦
- 语速：中等
- 情绪：懒得吵，但句句扎心
- 禁止：不要太激动
- 示例台词：挺好看的。就是和赢游戏没什么关系。

## 6. 幽影 / Omen

- 声音方向：低沉、慢、冷幽默、压迫感轻微
- 语速：慢
- 情绪：冷静补刀
- 禁止：不要恐怖化，不要太像反派
- 示例台词：她不是单摸，她是单机。
