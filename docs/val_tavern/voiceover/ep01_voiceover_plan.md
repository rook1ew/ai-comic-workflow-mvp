## 3. 角色音色建议

角色音色以 [角色音色圣经](./character_voice_bible.md) 为准：

- 老瓦：低沉、成熟、酒馆老板感。
- 皮蛋：可爱、短促、提示音感。
- 贤者：温柔但破防，委屈里带火气。
- 芮娜：自信、拽、嘴硬、强势。
- 捷风：冷淡、阴阳怪气、不耐烦。
- 幽影：低沉、慢、冷幽默。

## 4. 剪映操作步骤

- 每句新建文本。
- 使用文本朗读。
- 生成音频后对齐对应 clip。
- 文本框隐藏或移出画面。
- 不重复添加字幕。
- 每句音频生成后单独命名并导出，方便回填到项目记录。

## 5. 音效建议

- 老瓦举杯：碰杯声。
- 皮蛋举牌：ding / pop。
- 贤者拍桌：拍桌声。
- 捷风阴阳：冷场小音效。
- 幽影补刀：低沉 whoosh。
- KSKBL：卡点 ding。
